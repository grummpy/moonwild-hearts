# Creating the Full Asset Pack Release

The complete media pack (art, videos, environments, dances, combat cutscenes, etc.) is ~224 MB and is not in the git tree.

## How to create the GitHub Release (you do this once — takes 2 minutes)

1. Go to: https://github.com/grummpy/moonwild-hearts/releases/new
2. **Tag**: `v1.1.0` (create new tag)
3. **Release title**: `Moonwild Hearts v1.1 Full Asset Pack`
4. **Description** (copy-paste):

```
Full playable package with all graphics, videos, systems, barbarian player, 6 Moonkin companions, explorable world, crafting, leveling, consistent time, combat, and intimacy assets.

- Open game.html after unzipping
- Adults 18+ only
- All media included
```

5. Drag-and-drop (or choose file) the zip:
   `Moonwild_Hearts_v1.1_FULL_Complete_Asset_Pack.zip`
   (download it first from Google Drive if needed — see link below)
6. Check **Set as the latest release**
7. Click **Publish release**

After publishing, the public download link will be:
https://github.com/grummpy/moonwild-hearts/releases/tag/v1.1.0

(or the direct asset download URL shown on the release page)
