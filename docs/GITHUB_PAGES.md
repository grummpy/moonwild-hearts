# GitHub Pages Deploy

To host the playable browser version publicly:

1. Repo Settings → Pages → Source: Deploy from a branch
2. Branch: `main` / folder: `/ (root)`
3. Save
4. After a minute your game will be live at:
   https://grummpy.github.io/moonwild-hearts/game.html

Optional: add a custom domain later.

Note: Large media (videos/images) are not in the repo. The game still runs fully for systems (farm, craft, time, skills, explore). Drop media folders next to game.html for full visuals.
